**关键事实**：
- `v0.2.04exp` 的 `mod_info.json` 里 `gameVersion` 仍是 **`0.98a-RC8`**，jar 的 class major = **61（Java 17）** ⇒ **与本机游戏版本完全匹配，可以直接装**。
- 0.2x 系列全是 **prerelease（实验版）**，上游尚未放出 0.2 的正式版。
- ⚠️ **上游 GitHub 仓库的 `main` 分支严重落后**：tag `v0.2.04exp` 只有 83 个 `.java`，而官方发布包里有 **147 个**（多出整个 `Render` 子系统等 63 个文件），且共有的 83 个文件**内容全都不同**。
  ⇒ **必须以官方发布包为基准**，不要用仓库源码。

## 4. 新版 jar 的离线验证结果

- 标识符含 CJK = 0 ✔
- 类加载：**589/599 通过**，10 个失败**全部是我离线测试的局限，不是 mod 缺陷**：
  `RTS_GenericDrawMeth`/`RTS_FighterSquares`/`RTS_MiniMapRenderer` 及其内部类在 `<clinit>` 里调
  `Global.getSettings().loadText(...)` / `getSprite(...)`；离线无游戏上下文 ⇒ `Global.getSettings()` 为 **null** ⇒ NPE。
  游戏内这两个 API 正常（0.1.9c 没有渲染子系统、类加载期不取 settings，所以当时全过）。
- 实例化：139 个可实例化类全部通过，0 链接错误。

**附带发现（上游问题，非我方引入）**：`RTS_RenderManager` 引用了 `data/shaders/test.frag`，
但发布包 `data/shaders/` 下**没有该文件**（`data/shaders/Unused/test.frag` 倒是有一个）。
该引用位于测试路径，是否影响运行需游戏内实测；**不在汉化范围内**，仅记录。

## 5. 两个决策点（需确认后再动手）

1. **是否以 `v0.2.04exp` 替换已装的 0.1.9c？** 它是**实验版**（上游未发正式版）。换上去等于让玩家用实验版。
2. **那 10 条新译文谁来译？** 其余 165 条会从旧汉化自动复用（逐条对应，不重译）。
