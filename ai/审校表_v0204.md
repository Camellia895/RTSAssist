### 需要你拍板的术语点

1. **`Render` 译作「渲染」**：上游把界面里的 "UI" 统一改称 "Render"（`UI Settings`→`Render Settings`、`UI Scaling`→`Render Scaling`、`UI Command Volume`→`Render Command Volume`）。
   我按「渲染」译。若你觉得对玩家太技术化，可统一换成**「画面」**（则 4 条同步改）。
2. **`Render Command Volume` 我译作「指令音量」**（未带"渲染"前缀）：它位于「渲染设置」页签下，且已同页的说明写明是"下达指令的音频反馈"；
   旧译是「界面指令音量」。若要严格对应原文可改回**「渲染指令音量」**。
3. **zoom 系列口径**（沿用你 0.1.9c 的三种说法，如需统一请指明）：
   - `Maximum Zoom` / `Minimum Zoom` → **「最大/最小缩放级别」**（与旧译 `最大缩放级别` 一致）
   - `How far the player can zoom out.` → 「视角可向外拉远的最大视野距离。」（旧译原样）
   - `How far the player can zoom in.` → 「视角可向内拉近的最大视野距离。」（**我新译的对偶句**）
4. **`Zoom Sensitivity` → 「缩放灵敏度」**、说明句 → 「滚轮缩放的灵敏度。」（原句 `How sensitive the scroll wheel is.`）
5. **Config.ini 两条新注释**用了「缩放灵敏度 / 最小缩放级别」，与上面第 3、4 点保持同词。
